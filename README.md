# 🩸 Painel de Doadores

## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **painel interativo** no **Microsoft Excel**, criado para facilitar a análise e visualização de informações sobre doadores de sangue.

O dashboard foi desenvolvido aplicando conceitos de organização de dados, visualização de informações e Business Intelligence, permitindo uma análise rápida por meio de filtros dinâmicos.

---

## 🎯 Objetivo

Criar um painel intuitivo para apoiar a consulta e análise dos dados dos doadores, proporcionando uma visualização clara das informações por **Estado** e **Região**.

---

## 🚀 Funcionalidades

- Dashboard interativo
- Segmentação de dados (Slicers)
- Filtro por Estado
- Filtro por Região
- Indicadores dinâmicos
- Visualização organizada dos dados
- Tabela auxiliar para enriquecimento das informações geográficas
